## 👋 About Me

Hi, I'm Mehedi — a full-stack developer from Bangladesh 🇧🇩

My primary stack is PHP, Laravel, MySQL, and Vue.js. I enjoy building practical web applications, from e-commerce platforms and business management systems to APIs and custom workflows.

### What I Work On

- Laravel and PHP application development
- E-commerce platforms and business management systems
- REST APIs and third-party integrations
- Authentication, authorization, and modular application architecture
- Database design, reusable components, and business logic
- Frontend development with Vue.js, JavaScript, and modern CSS frameworks
- Python scripts for automation and utilities
